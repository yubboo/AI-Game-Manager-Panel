# XiaoYu Core

XiaoYu is not a new model. It is AGMP's Agent identity wrapped around the provider/model selected by the user.

```text
User goal
  -> configured vendor model
  -> tool call
  -> TS approval / policy
  -> Rust capability + native execution (when needed)
  -> observation
  -> same configured vendor model
```

Skills and future Memory make the model more reliable in game hosting; they must not reduce its native reasoning ability. A fixed `deployMinecraft()` orchestration pipeline is forbidden.
