## Stable baseline

## 0.2.9 changes

- Language ownership is frozen: **Rust = XiaoYu Agent Runtime**, **Go = AGMP Domain Host**, **Vue/TypeScript = UI**.
- First real Rust-first migration: `tools/search` / Capability Discovery is owned by `xiaoyu-core`; Go supplies the canonical Domain Tool catalog and keeps a migration-only fallback.
- Real lock files generated by the 0.2.8 GitHub Runner are committed: Go modules, Cargo, Frontend pnpm and Electron pnpm.
- CI uses Cargo `--locked`, pnpm `--frozen-lockfile`, and Go module verification/tidy diff.
- Architecture, project rules, module rules, source-tree gates and developer helper rules now enforce the Rust/Go/Vue ownership boundary.

## Current migration boundary

Still in Go for compatibility:

- model-provider HTTP transport;
- existing Agent Loop orchestration;
- existing shared generic process runtime;
- AGMP Domain Tool registry and game/product services.

New generic Agent Runtime work should go to Rust first. Do **not** duplicate mature Go Domain Services in Rust. Migration requires protocol tests and Agent Bench coverage before old paths are removed.
