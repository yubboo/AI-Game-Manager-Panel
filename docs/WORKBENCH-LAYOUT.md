# AI Game Manager Panel 可拖拽三栏工作台

AI Game Manager Panel 主界面固定采用三栏职责模型。**0.1.94 起，大屏首次进入时的目标初始比例调整为 5% / 75% / 20%**：左侧一级导航尽量精简，中央保持主工作区，右侧为上下文与二级菜单提供更充足的操作空间。

## 0.1.94 冻结结构

```text
┌────────────┬────────────────────────────────────┬────────────────────┐
│ 左侧一级   │ 中央主工作区                       │ 右侧上下文         │
│ 导航       │ 当前页面 / 小鱼对话 / 任务内容     │ 二级菜单 / 状态    │
│ 初始约5%  │ 初始约75%                          │ 初始约20%          │
│ 可拖拽     │ 优先保证约 75% 的主空间      │ 可拖拽             │
│ 可收起     │                                    │ 可收起             │
├────────────┴────────────────────────────────────┴────────────────────┤
│ Bottom Panel：终端 / 日志 / 任务输出，可拖拽高度                    │
└──────────────────────────────────────────────────────────────────────┘
```

桌面常用分辨率会尽量贴近 10 / 60 / 30；为了保证文字可读性和极端超宽屏不过度拉伸，左右栏仍有最小/最大宽度保护。因此在较窄窗口或超宽窗口上比例可以有小幅偏差。窄窗口继续优先自动隐藏右侧栏。

## 三栏职责

- **左栏：一级导航。** 只回答“我要去哪一个产品模块”。默认更窄，不塞页面内部设置分类。
- **中央：主工作区。** 只承载当前任务正文、表单、对话、运行结果；默认保持约 75% 左右或更多空间。
- **右栏：上下文 / 二级菜单。** 设置中心分类、小鱼 Runtime/审批/Tool/Harness 摘要、当前页面上下文都放在这里；默认约 20%。
- **Bottom Panel：终端 / 日志 / 任务输出。** 不与中央工作区争抢横向空间。

左右栏隐藏时 Vue 组件直接卸载，不保留空白列；Topbar 提供恢复入口。Bottom Panel 关闭后中央工作区自动收回垂直空间。

布局持久化键升级为 `agmp.workbench.layout.v4`。这是有意的布局迁移：0.1.94 第一次启动会采用新的 5 / 75 / 20 初始宽度，而不是继续读取 0.1.93 的旧宽度。之后用户手动拖拽的宽度仍会正常持久化。


## 0.1.95 Split Pane 修正

5 / 75 / 20 只表示首次目标比例。左侧一级导航在大屏下最小 220px，以保证品牌、一级菜单和状态信息可读。左右拖拽器互不修改对方宽度；中央使用剩余空间，并仅通过 `centerMin` 防止被两侧完全挤没。拖拽过程中只更新内存状态，pointerup 后一次性持久化。

小鱼中央工作区采用单一会话流：用户消息与小鱼回复在同一滚动区域内，composer 固定在底部；Enter 发送，Shift+Enter 换行。

## 0.1.95 独立 Splitter 与对话工作台

- 左栏、右栏各自保存像素宽度；拖右栏不会重算左栏，拖左栏也不会改右栏。
- 左栏最小宽度 220px（窄屏 168px），右栏最小宽度 260px（窄屏 230px）；到达边界后只停止当前拖拽方向，不再把文字压成竖排。
- 中央栏永远是 `minmax(0, 1fr)`，只消费左右栏之后的剩余空间，并保留中央最小工作宽度。
- 小鱼页面采用单一对话线程：历史消息位于同一个滚动区，Composer 固定在底部；Enter 发送，Shift+Enter 换行。
- XiaoYu 的 `ui.navigate` 只允许白名单站内页面，并通过当前 Run 的 sessionId 将导航动作送回发起它的客户端；不允许任意 URL 或直接 DOM 点击。
