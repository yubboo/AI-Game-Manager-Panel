- 菜单 5（快速检查）、6（完整检查）、18（一键打包）以及首次初始化都会提前执行该自检。
- 保留 0.1.57 Bonfire 专用 pnpm Store 与 ENOENT 自愈逻辑。
- 不修改稳定的 Wails / Electron 底层 Release BAT 构建实现。
