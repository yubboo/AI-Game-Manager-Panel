# AI Game Manager Panel 游戏工作台设计

当前版本：0.1.16

## 核心定位

AI Game Manager Panel 的“游戏库”不是 Steam 应用列表，也不是应用商店或收藏夹，而是：

> 进入各款游戏开服工作台的统一入口。

## 页面层级

```text
游戏库
├─ 饥荒联机版
├─ 幻兽帕鲁
├─ 僵尸毁灭工程
├─ 七日杀
└─ 添加其他游戏
```

每款真正接入的游戏拥有自己的 Game Workspace。

## DST 当前流程

```text
点击 饥荒联机版
      ↓
自动检测 Steam
      ↓
检测游戏本体 322330
      ↓
检测 Dedicated Server 343050
      ↓
缺失 → 环境准备
完整 → DST Workspace
```

工作台子功能预留：概览、房间、存档、世界、Mod、令牌、玩家、控制台、备份、安装与更新。

## 真实数据原则

- 不把所有 `appmanifest_*.acf` 自动展示到游戏库。
- 只按当前游戏需要的 AppID 做定向识别。
- AppID 完整显示，不截断。
- 安装状态必须同时以 Steam manifest 和实际安装目录为依据。
- 规划中的游戏不能伪造“已支持”状态。
