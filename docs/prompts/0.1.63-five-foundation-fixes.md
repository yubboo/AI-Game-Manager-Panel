问题一：首次启动页面布局错误
============================================================

A. 页面左上品牌区

============================================================

意义：

UserID

============================================================
【MachineCode】
============================================================

Windows：

读取稳定系统标识，

不得直接显示原始 MachineGuid。

格式例如：

BFM-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX

不要写死 Windows MachineGuid。

MachineCode：

代表“设备”。
