# AI Game Manager Panel 开发提示词归档

此目录专门保存进入正式开发/修复流程的提示词与实施约束。

规则：

1. 每个正式版本如存在用户确认的开发提示词，必须在开发开始前归档到 `docs/prompts/`。
2. 文件名使用 `<version>-<topic>.md`，例如 `0.1.63-five-foundation-fixes.md`。
3. 归档文件用于追溯需求，不替代 `AGENTS.md` 的永久开发规范。
4. 已归档历史提示词不得为了“同步新需求”直接改写；新需求应新建对应版本/主题文件。
5. Validation Report 必须注明本次实现对应的提示词文件。
